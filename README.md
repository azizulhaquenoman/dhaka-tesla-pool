# Dhaka Tesla Pool

This repository contains the Dhaka Tesla Pool web application and server.

## Web application

The frontend is a React application powered by Vite.

### Development

```bash
cd dhaka-tesla-pool-web
npm install
npm run dev
```

The frontend uses Vite for development and production builds.

## Server

The backend is located in `dhaka-tesla-pool-server`.

## Project structure

```text
dhaka-tesla-pool-web/     React + Vite frontend
dhaka-tesla-pool-server/  Node.js backend
```
